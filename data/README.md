# Raw data

Place the team's raw dataset here as `customer_churn.csv`, then run
`Data_Preparation/data_preparation.ipynb`.

If the file is named differently, edit the `RAW` path in the first code cell of
that notebook rather than renaming the file — keeping the original filename
makes the data source traceable.

Everything in `Data_Preparation/` and `Clustering_Analysis/` is generated from
this file, so it is the one input the whole pipeline depends on.
